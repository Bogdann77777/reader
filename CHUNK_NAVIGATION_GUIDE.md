# CHUNK NAVIGATION - User Guide

## ✅ ДОБАВЛЕНА НАВИГАЦИЯ ПО ЧАНКАМ

Теперь можно **вручную переключать чанки** без необходимости ждать воспроизведения всего текста.

---

## 🎮 КАК ИСПОЛЬЗОВАТЬ

### 1. КНОПКИ НАВИГАЦИИ

После загрузки текста появится панель навигации с:
- **`←`** - Предыдущий чанк
- **`→`** - Следующий чанк
- **Поле ввода** - Быстрый переход к номеру чанка
- **`GO`** - Перейти к введенному чанку

### 2. КЛАВИАТУРНЫЕ СОКРАЩЕНИЯ

- **`←` (Left Arrow)** - Предыдущий чанк
- **`→` (Right Arrow)** - Следующий чанк  
- **`Space`** - Play/Pause (если текст загружен)

### 3. БЫСТРЫЙ ПЕРЕХОД

Если у тебя 1000 чанков и нужно попасть на 535:

1. Кликни в поле ввода
2. Введи `535`
3. Нажми `Enter` или кнопку `GO`

---

## 📍 АВТОСОХРАНЕНИЕ ПОЗИЦИИ

- Текущая позиция **автоматически сохраняется** в localStorage
- При перезагрузке страницы продолжишь с того же места
- Навигация работает **во время воспроизведения** - можно переключать чанки "на лету"

---

## 💡 ВОЗМОЖНОСТИ

### Переключение во время воспроизведения:
✅ Если музыка играет и ты нажмешь `→`, текущий чанк остановится и начнется следующий

### Дисплей:
```
Chunk: 160 / 1000
[←] [Go to chunk...] [GO] [→]
```

### Статус кнопок:
- `←` disabled если ты на первом чанке
- `→` disabled если на последнем чанке
- Все кнопки disabled пока текст не загружен

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Обновленные файлы:
1. **`templates/index.html`** - Добавлена HTML разметка навигации
2. **`static/css/style.css`** - Стили для панели навигации
3. **`static/js/app.js`** - Логика навигации и клавиатурные сокращения

### Функции JavaScript:
- `previousChunk()` - Переход назад
- `nextChunk()` - Переход вперед
- `goToChunk()` - Переход к конкретному номеру
- `updateChunkNavigation()` - Обновление UI
- `setChunkNavigationEnabled()` - Включение/выключение контролов

## ✨ ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

**Сценарий 1: Ты остановился на 160-ом чанке**
1. Введи `160` в поле
2. Нажми `GO`
3. Нажми `START` для воспроизведения

**Сценарий 2: Быстрое пролистывание**
1. Нажимай `→` многократно
2. Или держи `→` зажатым (автоповтор)
3. Когда найдешь нужное место - `START`

**Сценарий 3: Проверка конкретного места**
1. Останови воспроизведение (`STOP`)
2. Введи номер чанка
3. Нажми `START` для прослушивания
4. Если не то место - переключи дальше кнопками
