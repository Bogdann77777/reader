# TTS Reader - Project Scope

## Описание проекта
Локальная читалка текстов с озвучкой через XTTS v2 (zero-shot). Веб-интерфейс для загрузки текста, выбора голоса и управления воспроизведением.

---

## Основные функции

### 1. UI Интерфейс
- **Загрузка текста**: Drag & Drop область для загрузки текстовых файлов
- **Отображение текста**: Текстовое поле с возможностью выделения позиции для старта
- **Управление воспроизведением**:
  - Кнопка START - начать чтение с начала или с выделенной позиции
  - Кнопка STOP - остановить чтение и сохранить позицию
  - Индикатор текущей позиции чтения
- **Выбор голоса**: Dropdown меню с динамическим списком голосов из папки `samples/`
- **Индикатор состояния**: Показывает статус (готов, читает, остановлено)

### 2. Обработка текста
- **Очистка от спецсимволов**:
  - Удаление: скобки (), [], {}, «», "", '', <>
  - Удаление: кавычки всех типов
  - Удаление: #, @, $, %, ^, &, *, _, +, =, |, \, ~, /, `
  - Сохранение: точка, запятая, восклицательный знак, вопросительный знак, тире, двоеточие, точка с запятой
  
- **Разбивка на блоки**:
  - Оптимальный размер блока: 300-500 символов
  - Разбивка по законченным предложениям (по точке, !, ?)
  - Сохранение контекста между блоками

- **Сохранение позиции**:
  - Автоматическое сохранение позиции при остановке
  - Восстановление позиции при следующем запуске
  - Хранение в localStorage браузера

### 3. TTS Engine (XTTS v2)
- **Модель**: tts_models/multilingual/multi-dataset/xtts_v2
- **Устройство**: CUDA (GPU) / CPU fallback
- **Языки**: Русский (основной), возможность переключения

- **Параметры для естественного чтения**:
  - Speed: 1.0 (естественная скорость)
  - Temperature: 0.75 (вариативность интонаций)
  - Length penalty: 1.0
  - Repetition penalty: 5.0 (избегаем повторений)
  
- **Обработка пунктуации**:
  - Точка: пауза 0.4 сек
  - Запятая: пауза 0.2 сек
  - Вопросительный знак: повышение интонации + пауза 0.5 сек
  - Восклицательный знак: эмоциональная интонация + пауза 0.5 сек
  - Тире: пауза 0.3 сек
  - Двоеточие: понижение интонации + пауза 0.3 сек

### 4. Управление голосами
- **Папка samples**: `samples/` в корне проекта
- **Формат файлов**: WAV (16kHz или 22kHz, моно/стерео)
- **Длительность образцов**: 6-10 секунд для качественного клонирования
- **Автоматическое сканирование**: При запуске приложения сканируется папка
- **Отображение в UI**: Имя файла без расширения = имя голоса в меню

### 5. Управление аудиофайлами
- **Генерация**: Каждый блок генерируется в отдельный файл
- **Папка вывода**: `audio_output/` (создается автоматически)
- **Автоудаление**: После проигрывания блока файл удаляется
- **Очистка при старте**: При новом запуске чтения все старые файлы удаляются

## Технический стек

### Backend
- **Python 3.10+**
- **Flask** - веб-сервер
- **TTS (Coqui)** - библиотека XTTS v2
- **PyTorch** - для работы с моделью
- **torchaudio** - обработка аудио

### Frontend
- **HTML5** - структура
- **CSS3** - стилизация
- **Vanilla JavaScript** - логика UI
- **Web Audio API** - воспроизведение аудио
- **Drag & Drop API** - загрузка файлов

### Storage
- **localStorage** - сохранение позиции чтения
- **FileSystem** - временное хранение аудио

## API Endpoints

### GET `/`
- Главная страница приложения

### GET `/api/voices`
- Возвращает список доступных голосов
- Response: `[{"name": "voice1", "path": "samples/voice1.wav"}, ...]`

### POST `/api/process_text`
- Обрабатывает загруженный текст
- Body: `{"text": "...", "start_position": 0}`
- Response: `{"success": true, "chunks": [...], "total_chunks": 10}`

### POST `/api/synthesize`
- Генерирует аудио для блока текста
- Body: `{"text": "...", "voice_path": "...", "chunk_index": 0, "language": "ru"}`
- Response: `{"success": true, "audio_url": "/audio/chunk_0.wav"}`

### GET `/api/audio/<filename>`
- Отдает сгенерированный аудиофайл
- Response: WAV file (audio/wav)

### POST `/api/cleanup`
- Очищает все временные аудиофайлы
- Response: `{"success": true, "deleted": 5}`

### POST `/api/save_position`
- Сохраняет текущую позицию чтения (может быть в localStorage)
- Body: `{"position": 1500}`
- Response: `{"success": true}`

## Workflow

### 1. Инициализация
```
Старт приложения
  ↓
Загрузка XTTS v2 модели на GPU
  ↓
Сканирование папки samples/
  ↓
Отображение UI
```

### 2. Загрузка текста
```
Пользователь перетаскивает файл
  ↓
JavaScript читает файл
  ↓
Отправка текста на /api/process_text
  ↓
Очистка текста от спецсимволов
  ↓
Разбивка на блоки
  ↓
Возврат блоков в UI
  ↓
Отображение текста в интерфейсе
```

### 3. Выбор голоса
```
Загрузка списка голосов с /api/voices
  ↓
Отображение в dropdown меню
  ↓
Пользователь выбирает голос
  ↓
Сохранение выбора в переменную
```

### 4. Чтение текста
```
Пользователь нажимает START
  ↓
Определение стартовой позиции (начало или выделенное место)
  ↓
Цикл по блокам:
  ├── Отправка блока на /api/synthesize
  ├── Генерация аудио через XTTS v2
  ├── Возврат URL аудиофайла
  ├── Воспроизведение через Web Audio API
  ├── Подсветка текущего блока в UI
  ├── Удаление аудиофайла после воспроизведения
  └── Переход к следующему блоку
```

### 5. Остановка чтения
```
Пользователь нажимает STOP
  ↓
Остановка воспроизведения
  ↓
Сохранение текущей позиции (номер блока)
  ↓
Очистка всех временных аудиофайлов
  ↓
Обновление UI (кнопка STOP → START)
```

## Ключевые особенности

### Максимально естественное чтение
1. **Обработка пунктуации**:
   - Паузы разной длины в зависимости от знака
   - Интонационные изменения (вопрос, восклицание)

2. **XTTS v2 настройки**:
   - Использование оптимальной температуры для вариативности
   - Repetition penalty для избежания монотонности
   - Zero-shot клонирование для естественности голоса

3. **Контекст между блоками**:
   - Небольшое перекрытие между блоками для плавности
   - Сохранение интонационного контекста

### Производительность
- **GPU ускорение**: Использование CUDA для быстрой генерации
- **Асинхронная генерация**: Генерация следующего блока во время воспроизведения текущего
- **Автоматическая очистка**: Экономия дискового пространства

### Удобство использования
- **Простой интерфейс**: Минималистичный дизайн
- **Drag & Drop**: Быстрая загрузка файлов
- **Гибкий старт**: С начала или с любой позиции
- **Автосохранение**: Позиция сохраняется автоматически

## Ограничения и известные проблемы

1. **Скорость генерации**: XTTS v2 генерирует ~1 секунду аудио за 0.5-1 секунду (на GPU)
2. **Размер модели**: ~2GB, требует время на первую загрузку
3. **Качество клонирования**: Зависит от качества sample файлов
4. **Длинные тексты**: Может занять время на обработку очень больших файлов (>100000 символов)

## Документация для пользователя

### Установка
1. Установить Python 3.10+
2. Установить CUDA Toolkit (для GPU)
3. Установить зависимости: `pip install -r requirements.txt`
4. Создать папку `samples/` и добавить WAV файлы голосов
5. Запустить: `python app.py`
6. Открыть браузер: `http://localhost:5000`

### Подготовка голосов
1. Записать аудио 6-10 секунд чистой речи
2. Формат: WAV, 22050Hz, моно
3. Назвать файл понятным именем (например, `male_deep.wav`)
4. Поместить в папку `samples/`
5. Перезапустить приложение

### Использование
1. Перетащить текстовый файл в область загрузки
2. Выбрать голос из выпадающего меню
3. Опционально: выделить мышью место для старта
4. Нажать START
5. Для остановки нажать STOP (позиция сохранится)
