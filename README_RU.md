# TTS Reader - Читалка с озвучкой

Локальная читалка текстов с озвучкой через XTTS v2 (zero-shot voice cloning).

## Быстрый старт

### 1. Установка зависимостей

Запустите файл:
```
install.bat
```

Это установит все необходимые библиотеки (займет 5-10 минут).

### 2. Конвертация голосов (уже выполнено!)

✅ В папке `samples/` уже есть 3 готовых WAV файла:
- gilkova-tonya-chistyy-golos.wav (36 сек)
- brik-inga-audiokniga.wav (45 сек)
- Вершинин Петр_Пример аудиокниги.wav (34 сек)

Если нужно добавить новые MP3 файлы:
1. Поместите MP3 файлы в папку `samples/`
2. Запустите `convert_audio.bat`

### 3. Запуск приложения

Запустите файл:
```
start.bat
```

Приложение откроется по адресу: **http://localhost:5000**

## Использование

1. **Выберите голос** из выпадающего списка
2. **Загрузите текстовый файл** (перетащите или нажмите на область загрузки)
3. **Нажмите START** для начала чтения
4. **STOP** - остановить чтение (позиция сохранится)
5. **CLEANUP** - удалить временные аудиофайлы

## Особенности

- **CPU режим** - работает без GPU (медленнее, но не требует NVIDIA)
- **Автоматическая очистка** - временные файлы удаляются после прослушивания
- **Сохранение позиции** - можно продолжить с места остановки
- **Разбивка текста** - автоматическое деление на блоки 300-500 символов
- **Естественное чтение** - паузы по пунктуации, интонации

## Системные требования

### Минимальные
- Python 3.10+
- 8 GB RAM
- 5 GB свободного места на диске
- Windows 10/11 или Linux

### Рекомендуемые
- Python 3.10+
- 16 GB RAM
- NVIDIA GPU с CUDA (для быстрой генерации)

## Проблемы и решения

### Приложение не запускается
- Убедитесь, что установлены все зависимости: запустите `install.bat`
- Проверьте, что Python 3.10+ установлен: `python --version`

### Медленная генерация
- Это нормально для CPU режима (~2-5 сек на секунду аудио)
- Для ускорения требуется NVIDIA GPU с CUDA

### Нет голосов в списке
- Проверьте наличие WAV файлов в папке `samples/`
- Конвертируйте MP3: `convert_audio.bat`

## Добавление своих голосов

1. Запишите аудио 6-10 секунд чистой речи
2. Сохраните как MP3
3. Поместите в папку `samples/`
4. Запустите `convert_audio.bat`
5. Перезапустите приложение
